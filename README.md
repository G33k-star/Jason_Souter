# Jason Souter
Electrical Engineering student focused on embedded systems, digital signal processing, and intelligent sensing. I’m interested in building systems that connect physical measurements to real-time computation—from sensors and analog interfaces to signal processing, embedded software, and autonomous decision-making. My projects explore the intersection of embedded computing, sensing, instrumentation, signal processing, and electromagnetic systems, with an emphasis on understanding the complete measurement-to-decision pipeline.
